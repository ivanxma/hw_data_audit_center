Image releases

Builds run on this OL9 VM and upload to the selected private OCI Registry repository.

Build & publish image

The VM builds the installed application source and uploads it using its instance principal. History writer releases use historywriter-<UTC timestamp>-<revision>; Debezium releases use debezium-<UTC timestamp>-<revision>. Select the completed release in Workload settings to deploy it.

Workload settings

Build and publish a release in Container Registry, then select it here. OCI Container Instances pull using their resource principal by default; their dynamic group needs read access to the private repository. Each deployment pins the selected release digest. Existing instances keep their deployed revision.
