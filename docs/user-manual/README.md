# HeatWave Audit Center user manual

Independent prototype for evaluation and rehearsal. This is not an Oracle product
and is not supported or endorsed by Oracle.

| Format | Manual |
| --- | --- |
| HTML | [Browse the illustrated manual](html/index.html) |
| PDF | [Download the printable manual](pdf/HeatWave-Audit-Center-User-Manual.pdf) |
| Markdown | [Read the Markdown manual](md/README.md) |

All editions cover setup, fields/actions, screenshots, architecture/network
diagrams, operational limitations, scaling, upgrades and cleanup. Appendix K
explains the same-compartment limitation for Vaults, secrets and other OCI
resources, including the limits of host-only database registration.

Screenshots are shared under `assets/`; editable architecture diagrams and their previews are under `diagrams/`.
